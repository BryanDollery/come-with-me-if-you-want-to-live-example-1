# Development Processes

1. Read specs and models before proceeding
2. Take the next highest priority task from `05 - tasks.md`
3. Think through the task, identifying any assumptions or decisions that need to be made, writing a managed todo list of subtasks as needed
4. Check the task list with me
5. Update the `05 - tasks.md` file with tasks as needed
6. Do the work, checking assumptions and decisions with me as they arise
7. Write tests for the work as you go (if appropriate)
8. Check that the work has been completed as per the spec and task, running formal or ad-hoc tests as needed
9. Run all tests
10. Confirm with the user that the task is complete
11. Update the task list to mark the task as done
12. Commit the work with a generated message referencing the task
